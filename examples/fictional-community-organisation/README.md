# Worked Example — Wattle Creek Community Association

**Wattle Creek Community Association (WCCA) is fictional.**

WCCA is a volunteer-led community organisation that operates a small hall, runs weekly programmes, manages approximately 420 member records and employs two part-time staff. It has an annual operating budget of about $280,000.

The organisation is deliberately ordinary. It has enough work and accountability to need shared operating discipline, but not enough scale to justify a project-management or governance platform.

## Current situation

At the start of the example period WCCA is dealing with four material items:

1. replacement of a deteriorating hall roof;
2. replacement of a volunteer-built membership spreadsheet with a small hosted membership service;
3. preparation for the annual community open day;
4. refresh of financial delegations and privacy practices.

The four registers show the same operating picture from different angles without duplicating every detail.

## How the registers link

```text
Hall roof replacement
   |
   +--> R-01 water ingress before works
   |
   +--> D-01 select fixed-price contractor

Membership system replacement
   |
   +--> R-02 member data migration error
   |
   +--> Privacy Policy evidence/control changes
   |
   +--> D-02 retain old spreadsheet read-only for 90 days
```

The identifiers live inside the existing text fields rather than requiring extra columns.
